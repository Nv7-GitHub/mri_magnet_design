# Magnet holder CAD: generating, testing and building

This guide covers turning a magnet design (an Excel "ledger" of magnet positions) into printable holder parts, the
test coupons to print first, and how to assemble the magnet. Everything is generated by Python scripts with
[CadQuery](https://cadquery.readthedocs.io); no CAD program is needed except to view the results or design the end caps.

Design background (why the parts look like this, tolerance studies, bolt loads) is in [DESIGN_NOTES.md](DESIGN_NOTES.md).

## What gets made

For the recommended design (`results/BEST_bore100_cyl40x40_649mag_427ppm.xlsx`: 649 x 1/4" N42 cubes, 100 mm bore,
45 mT, 427 ppm over a 40 x 40 mm cylinder):

| Part | Process | Count | Notes |
|---|---|---|---|
| Ring slabs `slab_0` ... `slab_8` | SLA (Formlabs Form 4, Rigid 4000) | 9, all different | Magnet pockets open at the top face; 8.65-9.65 mm thick, OD 193.6 mm |
| Spacers `spacer_h<height>` | FDM (PETG or PLA) | 3 files, each printed 2x | Solid rings that fill the gaps between rings and cap the magnets of the ring below |
| SLA tolerance coupon | SLA, same as the rings | 1 | Pocket fit, thin walls, bolt holes |
| FDM tolerance coupon | FDM, same as the spacers | 1 | Spacer height accuracy, bolt holes |
| End caps | your own design | 2 | Not generated: close the top slab's pockets and clamp the stack |

Side view of the stack (z is the bore axis; B0 points along +x, marked by a V notch on the outside of every part):

```
  +z   end cap (yours)
       slab 8   [■ ■ ■]        pockets open at the top, closed by the end cap
       slab 7   [■ ■ ■]        slab 8 sits directly on slab 7 (rings only 9.35 mm apart)
       spacer_h6.06  ══════    FDM: solid ring; its bottom face caps slab 6's magnets, its height sets the gap
       slab 6   [■ ■ ■]
       spacer_h17.22
       slab 5   [■ ■ ■]
       spacer_h10.21
       slab 4   [■ ■ ■]        centre ring, z = 0
       spacer_h10.21
       slab 3   [■ ■ ■]
       spacer_h17.22
       slab 2   [■ ■ ■]
       spacer_h6.06
       slab 1   [■ ■ ■]
       slab 0   [■ ■ ■]        3 mm floor underneath
  -z   end cap (yours)
```

All parts share 8 M3 bolt holes outside the magnets and 6 M2 holes near the bore. One M3 hole is shifted 10 degrees off
the even spacing, so parts only stack in the correct rotation and the right way up.

## Setup

Python 3.12 and the project requirements (CadQuery is included):

```bash
git clone https://github.com/Nv7-GitHub/mri_magnet_design
cd mri_magnet_design
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Generated files go in `cad/`, which is git-ignored (the full set is ~200 MB). Regenerate them with the commands below.

## Quick start: generate everything with default settings

```bash
source .venv/bin/activate
python make_test_coupon.py --out cad/coupon            # SLA coupon            (~10 s)
python make_fdm_coupon.py  --out cad/fdm_coupon        # FDM coupon            (~5 s)
python make_coupons_step.py                             # both coupons in one STEP (~5 s)
python make_ring_cad.py results/BEST_bore100_cyl40x40_649mag_427ppm.xlsx --out cad/best --magnets   # (~2 min)
python check_bolt_loads.py results/BEST_bore100_cyl40x40_649mag_427ppm.xlsx                         # (~30 s)
```

The defaults are reasonable starting values, but **print and measure both coupons before printing the real parts**, then
regenerate with the values you measured (next section).

## Workflow

### 1. Print the SLA tolerance coupon

`cad/coupon/tolerance_coupon.stl` (81 x 66 x 8.7 mm). Print it **exactly like the rings**: same resin (Rigid 4000), same
orientation (standing on its long edge, as the rings stand upright on the Form 4), same wash and post-cure.

The layout is shown in `cad/coupon/tolerance_coupon.png`; every value is engraved next to its feature.

- **Pocket grid**: columns are the in-plane clearance added to the 6.35 mm cube (.05 to .30 mm), rows are the pocket
  rotation (0, 22.5, 45 degrees; the rings have pockets at every angle). Push a magnet into each. Pick the smallest
  clearance where the magnet goes in by hand and drops out when the coupon is turned over, **in all three rows**.
  That is `--tol X Y` (use the same value for both).
- **Thin-wall pairs** (`w0.6`, `w0.8`, `w1`): two pockets separated by 0.6 / 0.8 / 1.0 mm of resin. The rings have
  walls down to 1.02 mm. Check the walls printed cleanly and survive pushing magnets into both pockets.
- **Bolt holes** (M3 and M2 rows, clearance .1 to .6 mm per column): pick the smallest clearance a bolt slides through
  freely. That is `--outer-tol` (M3) and `--inner-tol` (M2).

### 2. Print the FDM tolerance coupon

`cad/fdm_coupon/fdm_coupon.stl` (74 x 63 mm). Print it with **the printer, material, layer height and slicer settings
you will use for the spacers**, flat on the bed.

- **Height samples** (6.06 / 10.21 / 17.22 mm, engraved in front): these are the three spacer heights. Measure each
  with calipers at its corners and centre and average. The spacers set the distance between magnet rings, which
  matters at the 0.05 mm level, so this is the most important measurement.
  `--spacer-comp` = nominal - measured (average over the three; e.g. if they print 0.10 mm tall, `--spacer-comp -0.1`).
  If the error grows with height (a scale error rather than a constant offset), fix the printer's z calibration or
  choose a layer height that divides the heights, then reprint the coupon.
- **Bolt holes** (M3 and M2 bars, clearance .2 to .7 mm): smallest clearance a bolt slides through freely.
  That is `--fdm-outer-tol` (M3) and `--fdm-inner-tol` (M2).

### 3. Generate the parts with your measured values

```bash
python make_ring_cad.py results/BEST_bore100_cyl40x40_649mag_427ppm.xlsx --out cad/best \
    --tol 0.15 0.15 0.3 \
    --outer-tol 0.4 --inner-tol 0.4 \
    --fdm-outer-tol 0.5 --fdm-inner-tol 0.5 \
    --spacer-comp 0.0 \
    --magnets
```

Replace the numbers with your coupon results. The third `--tol` value is the pocket depth clearance (vertical play;
the part above closes the pocket), 0.3 mm is fine.

Check the console output:

- one line per slab with its thickness, magnet count and thinnest walls (pocket to pocket, to the bore, to the outside,
  to the bolt holes), and one line per spacer with its height;
- `WARNING` lines for anything thinner than `--min-wall` (1.5 mm). Pocket-to-pocket walls of ~1.0-1.2 mm are expected
  for this design and are what the coupon's thin-wall pairs test; anything well below 1 mm deserves a look.

Then look at the loading guides `cad/best/slab_<i>_z<z>.png` and, in any CAD viewer, `cad/best/assembly.step`.

### 4. Print the rings (SLA)

- Form 4 (build volume 200 x 125 x 210 mm): the 193.6 mm rings fit only **standing upright** on edge.
- Rigid 4000 (glass-filled: stiff, low creep and low warp). Rigid 10K is stiffer but brittle (1% elongation).
- What matters for the field is that rings are **the same as each other and round**; a uniform shrink of all parts is
  harmless (see the warp study in DESIGN_NOTES.md). So: print every ring from the same resin batch with the same
  orientation, supports, wash and post-cure, and don't over-wash (solvent swelling warps parts).
- Turn every other ring 90 degrees about its own axis on the build plate, so any print ovality alternates direction
  through the stack instead of adding up. (This is only the print orientation. The parts always assemble in the
  keyed orientation set by the bolt holes.)
- Measure each ring's outer diameter at 4 angles and check it lies flat. Reprint anything out of round or warped by
  more than ~0.1 mm.

### 5. Print the spacers (FDM)

- The spacers are solid rings in CAD: the slicer adds walls and infill. Print them flat on the bed, no supports; the bed
  must be at least 194 mm. Use the same material, layer height, walls, infill and top/bottom layers as the FDM coupon
  (the coupon's height samples are solid blocks for the same reason), and enough top layers for a flat top face, since
  the top and bottom faces set the ring spacing.
- PETG or PLA.
- Print **two of each** spacer file (`spacer_h6.06`, `spacer_h10.21`, `spacer_h17.22`): the +z and -z spacers are the
  same part. `cad/best/spacers.csv` lists which slabs each one goes between.
- Measure every spacer's height at several points around the ring. It should match the height in its file name to
  within ~0.05 mm.

### 6. Assemble

Parts and hardware: the 9 slabs, 6 spacers, your 2 end caps, 649 magnets, 8 M3 and 6 M2 **brass** threaded rods
(about 160 mm plus the end caps) with brass nuts and washers. Use brass (or another non-magnetic metal); 18-8 stainless
threads can be slightly magnetic.

1. Put the threaded rods through the bottom end cap; they act as guide pins for the whole stack.
2. Lower `slab_0` over the rods (pockets facing up). The holes only line up one way.
3. Load its magnets: each pocket has a small V notch in the wall on one side. **The magnet's N face goes against the
   notch.** The loading guide PNG for each slab shows the same thing (red = N side). To find a magnet's N face, use a
   pole identifier or a compass: the compass needle's north-seeking end points at the magnet's **S** face.
4. Add the next part:
   - `slab_1` sits directly on `slab_0` and closes its pockets; `slab_8` likewise sits directly on `slab_7`;
   - every other slab gets its spacer first: slab 1 -> `spacer_h6.06` -> slab 2 -> `spacer_h17.22` ->
     slab 3 -> `spacer_h10.21` -> slab 4 -> `spacer_h10.21` -> slab 5 -> `spacer_h17.22` -> slab 6 -> `spacer_h6.06` ->
     slab 7 (the order is also in `cad/best/spacers.csv`).
   Load each slab's magnets before putting the next part on it.
5. Finish with `slab_8`, then the top end cap, which closes slab 8's pockets.
6. Tighten the nuts only snug (about 0.1-0.2 N m on M3 with washers). The joints need only 5-9 N per bolt to stay
   closed (`check_bolt_loads.py`); more just crushes or creeps the plastic.

Handling: the magnets attract and repel each other strongly at close range. Insert them one at a time with a
non-magnetic pusher and keep loose magnets away from the stack. Never let two cubes slam together or force two
repelling cubes face to face: that can partly demagnetize N42 at room temperature (see the README's demagnetization
section).

## Output files

`cad/best/` (from `make_ring_cad.py`):

| File | Contents |
|---|---|
| `slab_<i>_z<z>.stl` / `.step` | SLA ring `i` (0 = bottom, -z), holding the magnets at height `z` (mm) |
| `spacer_h<h>.stl` / `.step` | FDM spacer of height `h` (mm), modelled at z = 0; print one per position in `spacers.csv` |
| `slab_<i>_z<z>.png` | Loading guide: top view of the slab, each pocket with its N side in red, bolt holes, +x notch |
| `assembly.step` | Everything in place: `magnet_holder` > `sla_rings` (9 slabs, light grey) + `fdm_spacers` (3 spacer parts, each placed twice, blue) |
| `assembly_with_magnets.step` | Same plus `magnets`: one `magnet_6.35mm` part (red) placed 649 times (only with `--magnets`) |
| `slabs.csv` | Per slab: z range, thickness, magnet count, floor, thinnest walls, volume |
| `spacers.csv` | Per spacer position: which slabs it goes between, part file, z range, nominal and CAD height |

`cad/coupon/tolerance_coupon.{stl,step,png}` and `cad/fdm_coupon/fdm_coupon.{stl,step}` are the coupons.
`cad/test_coupons.step` (from `make_coupons_step.py`) holds both coupons side by side as separate bodies of one part,
with no assembly structure, so it imports into Onshape (or any CAD program) as a single Part Studio containing every
coupon. Run the coupon scripts first if you want non-default coupon settings; missing coupons are generated with
defaults.

The STEP files are what to design the end caps against: import `assembly.step`, and the end caps sit against the
bottom face of `slab_0` (z = -75.12 mm) and the top face of `slab_8` (z = +72.12 mm), sharing the bolt pattern.

## Script reference

All scripts print their full option list with `--help`. Lengths in mm.

### `make_ring_cad.py <ledger.xlsx>`

| Option | Default | Meaning |
|---|---|---|
| `--out` | `cad/out` | Output folder |
| `--tol X Y Z` | `0.15 0.15 0.3` | Pocket clearance on the magnet's local axes (x = magnetization, z = depth) |
| `--bore` | `100` | Inner diameter |
| `--od` | auto (193.6) | Outer diameter; default just fits the pockets and outer bolt holes |
| `--base` | `3` | Floor under slab 0's pockets |
| `--floor` | `2` | Floor under the pockets of the other rings |
| `--min-spacer` | `3` | Gaps shorter than this get no spacer; the ring sits on the one below |
| `--solid` | off | No spacers: every slab fills the gap below it (2.9 L of resin instead of 1.5 L) |
| `--spacer-comp` | `0` | Added to every spacer's CAD height (from the FDM coupon) |
| `--outer-holes`, `--outer-bolt`, `--outer-tol` | `8`, `3`, `0.4` | Outer bolts: count, diameter (M3), SLA clearance |
| `--inner-holes`, `--inner-bolt`, `--inner-tol` | `6`, `2`, `0.4` | Inner bolts: count, diameter (M2), SLA clearance; placed automatically where they clear all pockets |
| `--fdm-outer-tol`, `--fdm-inner-tol` | `0.5`, `0.5` | Bolt clearances in the FDM spacers |
| `--hole-key` | `10` | Angle one outer hole is shifted for keying (degrees) |
| `--hole-wall` | `0.8` | Minimum resin between an inner hole and the bore or a pocket |
| `--relief` | `0.4` | Corner relief radius in the pockets (0 = none) |
| `--air-d` | `1.5` | Air hole under each pocket (0 = none) |
| `--mark-width`, `--mark-height`, `--mark-depth` | `2`, `1`, `2` | N notch: width at the pocket face, how far into the wall, how deep from the top |
| `--notch` | `1` | Depth of the +x (B0) notch on the outside (0 = none) |
| `--min-wall` | `1.5` | Warn below this wall thickness |
| `--magnets` | off | Also write `assembly_with_magnets.step` |
| `--no-step` | off | STL and PNG only (faster) |

### `make_test_coupon.py` (SLA)

`--pocket-tols` (default `0.05 0.10 0.15 0.20 0.25 0.30`), `--angles` (`0 22.5 45`), `--walls` (`0.6 0.8 1.0`),
`--wall-tol` (`0.15`), `--bolts` (`3 2`), `--hole-tols` (`0.1 ... 0.6`), `--tol-z` (`0.3`), `--cube` (`6.35`),
`--relief`, `--air-d`, `--floor` (`2`), `--margin` (`2`), `--gap` (`1.8`), `--text`, `--text-depth`.
Uses the same pocket function as the rings, so a fit on the coupon is the fit in the rings.

### `make_fdm_coupon.py` (FDM)

`--heights` (default `6.06 10.21 17.22`, the spacer heights; take them from `spacers.csv` for another design),
`--bolts` (`3 2`), `--hole-tols` (`0.2 ... 0.7`), `--plate` (`1.6`), `--sample` (`20`), `--bar-h`, `--text`,
`--text-depth`.

### `make_coupons_step.py`

Combines the existing coupon STEPs into `cad/test_coupons.step` (one part, one named body per coupon). Options: `--out`,
`--gap` (space between coupons, default 10 mm).

### `check_bolt_loads.py <ledger.xlsx>`

Computes the magnetic force on every magnet (exact surface-charge model) and the tension each joint puts on each bolt,
using the same bolt positions as `make_ring_cad.py` (pass the same hole options if you changed them). For the
recommended design: at most 7.8 N per M3 and 3.1 N per M2, ~100x below the yield of brass bolts.

## Using a different magnet design

`make_ring_cad.py` accepts any ledger in the MRI4ALL format (columns `X-pos`, `Y-pos`, `Z-pos`, `X-rot`, `Y-rot`,
`Z-rot`, `Magnet_length`; mm and degrees; magnetization along each cube's local x), such as the `BEST_*`, `FINAL_*` or
`REFINED_*` files in `results/` or a new optimizer output. Limits:

- only rotations about z (`X-rot` = `Y-rot` = 0), which all Halbach ledgers here use;
- all magnets the same size;
- each distinct `Z-pos` becomes one ring.

For a different magnet size, also pass `--cube` to `make_test_coupon.py`. For a different design, regenerate the FDM
coupon with `--heights` set to the new spacer heights from `spacers.csv`.

## Limitations and notes

- End caps are not generated.
- M3 does not fit between the 100 mm bore and the inner magnets (only ~2.3 mm of resin there), hence M2 inside.
- The +z and -z rings are not identical (slab boundaries are not mirror symmetric), so all 9 slabs are separate files.
  The spacers come in identical +z/-z pairs, so there is one file per spacer height.
- In the assembly STEPs, repeated parts (the magnet cube, each spacer) are stored once and placed as instances, so a
  CAD program loads 13 bodies rather than 664. Some importers have an option to keep or break instances; keep them.
- STEP export of the full set takes a couple of minutes; use `--no-step` while iterating.
